# 播放器布局避让示例

需要带 `player.layout` 实验接口的宿主；旧版使用 `ctx.getLayout()` 的 1.x 示例不适用。
打包本目录为 ZIP 后通过模组管理安装并确认启用。无账号、网络请求或发送动作。

清单 opt-in `experimental: ["player.layout"]`；完整示例 UI 挂在已有
`stageLayers` 的 `app.overlay` 槽位，通过 `ui.stage` 权限追加。布局只读
`folium.experimental['player.layout'].get()` 和 `subscribe()`，不查询宿主 DOM，
也不重排、隐藏或替换原生控件。字体、圆角、颜色和避让算法全部由示例模组提供。

人工检查：

1. 进入播放页：左下聊天避开返回按钮、底栏和正在播放卡片，右上气泡避开真实相交的控件。
2. 打开未到顶的右侧面板：右上气泡有足够空间时保持原位；真正相交时才移动。
3. 鼠标移到返回按钮周围，包括示例聊天上方的唤出范围：返回按钮仍出现且可点。
4. 调整窗口大小、底栏高度、侧栏和 Toast：模组组件跟随几何更新，原生控件位置不变。
5. 切到首页：快照为空，示例隐藏。停用模组：组件和订阅消失；重新启用：只恢复一份。

几何通知合并到 80ms；这不是逐帧动画同步接口。示例可因可用区域太小而隐藏组件。
